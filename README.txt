WEBSITE ULANG TAHUN MAMAH — 10 NOVEMBER 2026
==========================================

CARA MEMBUKA
1. Ekstrak ZIP ini.
2. Klik dua kali file index.html di laptop.
3. Klik "Buka hadiahnya" untuk masuk. Buka bagian musik, lalu tekan putar di pemutar YouTube.
4. Gunakan "Tiup lilinnya" dan amplop untuk melihat kejutan.

CARA MEMASUKKAN FOTO PERMANEN
1. Di dalam folder ulang-tahun-mamah, buat folder bernama "foto".
2. Masukkan hingga empat foto dalam folder tersebut dengan nama:
   foto-1.png, foto-2.png, foto-3.png, foto-4.png
3. Refresh halaman. Keempat foto otomatis tampil.
   Alternatif: tekan tombol "Tambahkan foto kenangan" di website.
   Catatan: unggahan lewat tombol hanya sementara selama tab terbuka.

CARA BERBAGI LEWAT HP
- Untuk dibuka di HP orang lain melalui tautan, unggah folder website ini ke
  layanan hosting statis seperti Netlify Drop atau GitHub Pages.
- Pastikan folder "foto" ikut diunggah jika ingin menampilkan foto permanen.
- Membuka HTML dengan file lokal lewat HP juga memungkinkan di sejumlah browser,
  tetapi untuk pengalaman terbaik gunakan hosting statis HTTPS.

MUSIK
- Lagu diputar melalui pemutar YouTube resmi; perangkat perlu terhubung ke internet.
- Tekan tombol putar pada pemutar. Jika tidak tampil, gunakan tautan untuk membuka lagu di YouTube.

FILE
- index.html: struktur website
- style.css: desain dan tampilan responsif
- script.js: animasi, musik, surat, galeri, dan interaksi

CATATAN
- Font web memakai Google Fonts; ketika offline akan memakai font cadangan.
- Website tidak mengumpulkan atau menyimpan data pribadi. Pemutar YouTube memuat konten dari layanan Google/YouTube.
- Foto yang ditambahkan via tombol tidak diunggah ke internet.

Dari Aa, untuk Mamah tersayang. ♡
